# 法規導向改版待辦

依《專案計畫書 v3：法規限值導向》執行，順序如下。

## P0：先修正可能造成誤解的內容

- [ ] 首頁將「低效率風險」移至製程診斷，不再放在合規主卡。
- [ ] 首頁新增「適用法規尚未設定」阻擋狀態。
- [ ] 未設定業別、排放去向、所在地與許可證條件時，不顯示合格／不合格。
- [ ] 所有 AI 結果使用「預測超限風險」，與實測合規結果分開。

## P1：建立放流水濃度模型

- [ ] 以 UCI `SS-S` 為 SS 放流水回歸目標。
- [ ] 以 UCI `DQO-S` 為 COD 放流水回歸目標。
- [ ] 採時間留後切分，與最近值及歷史平均基準比較。
- [ ] 輸出 MAE、RMSE、R²、預測區間與資料期間。
- [ ] 將既有 `RD-SS-P` 模型改列輔助製程效率模型。

## P1：建立法規設定檔與規則引擎

- [ ] 設計可版本化 JSON schema：業別、排放去向、地區、污染物、上下限、單位、來源、生效日期與許可證覆寫。
- [ ] 規則優先序須涵蓋個案許可、地方加嚴、總量管制與中央基準；實際優先序須再由環保專業人員確認。
- [ ] 每次判定保存設定檔版本，避免法規更新後無法重現歷史結果。
- [ ] 缺少必要條件時回傳 `unassessed`，不得猜測限值。

## P2：重做前端資訊架構

- [ ] 總覽主卡顯示污染物、實測值、預測值、適用限值、餘裕、風險與資料時間。
- [ ] 趨勢圖分開呈現法定限值線、內部操作警戒線與預測區間。
- [ ] 新增法規設定頁，顯示官方來源、版本及生效日期。
- [ ] 新增事件頁，區分實測超限、預測預警、資料異常與模型異常。

## P2：實廠驗證

- [ ] 取得實廠進出水、流量、操作條件及許可資料。
- [ ] 依水力停留時間定義預報視窗。
- [ ] 以實際有效限值建立歷史事件標籤。
- [ ] 以漏報率、誤報次數及提前時間完成影子模式驗證。

## 完成定義

只有在適用法規設定完成、濃度模型通過時間外測試、每筆結果可追溯、且實廠影子驗證達標後，網站才可從「研究原型」改為「操作決策支援」。
